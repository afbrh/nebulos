# core-wonder: Super Mario Bros. Wonder 1.0.0 (Nintendo Switch)

The Odyssey/TOTKDroid native runtime (libsmo_main.so, ../../smorecomp-src, GAME_V_WONDER) with Wonder as its game: own process `:wonder`, own game files
`native-dumps/010015100B514000` (ExeFS + RomFS of the base game, hactool from the user's own XCI + prod.keys), own data root `files/wonder`, own saves `_Nebulos/wonder-core/save`,
own debug env file `runtime-env-wonder.txt`. Nothing is shared with another game. Notes: ../../wonder-research/PROGRESS.md.
