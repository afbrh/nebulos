Super Mario Bros. Wonder (Switch): "4:3 Aspect Ratio" by StevensND and KeatonTheBot, from "Aspect Ratio Mods" (gamebanana.com/mods/474766).
One .pchtxt per game version (1.0.0, 1.0.1 by the authors; 1.2.1 ported by Nebulos); each only applies to its own build id.
The game then renders for a 4:3 view; Nebulos stretches Eden's picture to fill the screen while this folder exists.
Installed by Nebulos (core-eden). Delete this folder to turn it off; Nebulos will not put it back.
v1.2.1 also carries a Nebulos HUD fit (HUD layouts squashed to fit the 4:3 picture and anchored to the screen edges); 1.0.0/1.0.1 keep the stretched HUD.
