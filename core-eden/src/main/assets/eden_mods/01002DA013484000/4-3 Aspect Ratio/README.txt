The Legend of Zelda: Skyward Sword HD (Switch), v1.0.1: "4:3 Aspect Ratio" by Nebulos (render size 960x720, HUD un-stretch). Based on the render-size locations documented by Fl4sh9174's resolution mods.
The game renders 960x720; Eden stretches it into its 16:9 picture and Nebulos stretches the picture back up to the full screen height while this folder exists.
Only applies to the v1.0.1 build id. Installed by Nebulos (core-eden). Delete this folder to turn it off; Nebulos will not put it back.
Menus: menu layouts get the same vertical un-stretch as the HUD (round circles, cursor still on its buttons). The pause screen's frozen-scene picture is cropped from 4:3 to 16:9: on the first launch Nebulos extracts Layout/MenuPause.arc from your own copy of the game, edits one picture's texture coordinates and saves it under romfs/Layout/ in this folder (nothing from the game is shipped with Nebulos). Delete this folder to turn all of it off.
